# WorkflowAudit

> Automated health audit reports for Make/Zapier/n8n workflows — catch fragility before it breaks.

## What is WorkflowAudit?

WorkflowAudit is built for **Automation consultants who want to upsell clients, and SMB owners who inherited workflows and want peace of mind**. Consultants can use it as a paid deliverable — the report IS the product they sell to clients, creating a built-in reseller channel

### Core MVP features
- Connect workflow via API/JSON export and run automated fragility scan
- Scored report: missing error handlers, hardcoded credentials, single points of failure, undocumented steps
- Priority-ranked fix list with plain-English explanations of each risk
- White-label PDF report for consultants to deliver to clients
- Scheduled re-audit with diff report showing what changed since last scan

**Pricing:** Per-report credits + white-label monthly subscription for consultants at $9 per one-time audit report; $99/month for consultants (unlimited audits + white-label branding)

## How this business runs itself (mailbox money)

The goal is passive, low-maintenance recurring revenue: AI is how we build and operate the business, not necessarily what it sells.

Workflow JSON is uploaded or pulled via API. A serverless function runs the audit rubric via OpenAI and scores each node. A PDF is generated via Puppeteer and emailed to the user. Stripe webhooks manage credit deductions and subscription state. A weekly cron re-audits subscribed workflows and emails diff reports. Owner time: under 1 hour/week.

**Estimated owner time:** ~1 hour(s)/week

**MVP estimate:** Next.js + Supabase + OpenAI + PDF generation (Puppeteer); 3 weeks; Make.com API first

## Local development

### Prerequisites

- **Node.js** 18.17 or later (20 LTS recommended)
- **npm** 9+ (bundled with Node)

No environment variables, database, or API keys are required — the demo runs entirely on hardcoded client-side mock data.

### Install and run

```bash
npm install
npm run dev    # http://localhost:3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

|-------|-------------|

### Production build


### Deploy to Vercel

1. Push this directory to a Git repository (GitHub, GitLab, or Bitbucket).
2. Import the repo at [vercel.com/new](https://vercel.com/new).
3. Vercel auto-detects Next.js — no configuration, environment variables, or custom server needed.
4. Click **Deploy**. The app is live at your `*.vercel.app` URL.

Alternatively, deploy from the CLI:

```bash
npx vercel
```
